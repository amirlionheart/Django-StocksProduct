# Stocks & Products API (Django REST Framework)

REST API для управления продуктами и складами.  
Проект реализует CRUD-операции, связь многие-ко-многим через промежуточную модель и поиск по данным.

---

## 🚀 Возможности проекта

### 📦 Products
- Создание продукта
- Получение списка продуктов
- Обновление продукта
- Удаление продукта
- Поиск по названию и описанию

### 🏬 Stocks
- Создание склада
- Получение списка складов
- Обновление склада
- Удаление склада
- Связь с продуктами через StockProduct
- Хранение цены продукта на конкретном складе
- Поиск складов по продуктам

## 🧠 Используемые технологии
- Python 3.10+
- Django
- Django REST Framework
- PostgreSQL
